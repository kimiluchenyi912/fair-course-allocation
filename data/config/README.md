# Configuration Data Notice

These files define a **TPHS-inspired synthetic model**. They are not official
TPHS or SDUHSD data, policy, enrollment, capacity, or schedule records.

- `model_assumption` values are explicit simulation choices.
- `student_estimate` values are synthetic assumptions informed by a student's
  recollection or planning notes; they are not verified school statistics.
- `student_provided_form` identifies course names or structures transcribed
  from a user-provided form; its public-source status has not been independently verified.
- Exact generated requests, student IDs, sections, and outcomes are synthetic.

Public users should replace these inputs with documented local assumptions or
properly authorized data before applying the framework elsewhere.
